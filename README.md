Descripción del proyecto

Este proyecto tiene como objetivo documentar el proceso de gestión de solicitudes de productos sin stock de la empresa On Electronics.
El sistema busca organizar el registro y seguimiento de las solicitudes de los clientes, la actualización del inventario, la asignación de stock disponible y las notificaciones sobre la disponibilidad de los productos.

Proceso de negocio

El proceso contempla las siguientes actividades:
- Consulta del cliente por un producto.
- Verificación de la disponibilidad de stock.
- Registro de solicitudes cuando no hay stock suficiente.
- Organización de las solicitudes pendientes por antigüedad.
- Asignación de mercadería disponible.
- Notificación al cliente cuando puede retirar el producto.
- Cancelación de solicitudes vencidas y liberación del stock reservado.
  
Modelado del proceso

El proceso organizativo se representa mediante un diagrama BPMN, utilizando pools, lanes, tareas, eventos, compuertas de decisión y flujos de secuencia y de mensaje.

Indicadores de control y estándares de desempeño

Para evaluar el funcionamiento del sistema de gestión de solicitudes de productos sin stock, se proponen los siguientes indicadores:

- Tiempo de registro: verificar que las solicitudes se registren correctamente cuando no hay stock suficiente.
- Exactitud de la asignación: comprobar que el sistema reserve las cantidades solicitadas sin superar el stock disponible.
- Orden de atención: verificar que las solicitudes pendientes se procesen desde la más antigua hasta la más reciente.
- Efectividad de las notificaciones: comprobar que se envíen los correos de disponibilidad y de cancelación por vencimiento cuando corresponda.
- Control de vencimientos: verificar que las solicitudes no retiradas dentro de los cinco días hábiles se cancelen y que el stock reservado se libere.
- Integridad del inventario: comprobar que el stock físico, reservado y disponible se actualice de manera coherente.

Estos indicadores constituyen criterios propuestos para la auditoría del sistema. Su cumplimiento deberá verificarse mediante pruebas del proceso y revisión de los resultados obtenidos.
