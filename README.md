Descripción del proyecto

Este proyecto tiene como objetivo documentar el proceso de gestión de solicitudes de productos sin stock de la empresa On Electronics.
El sistema busca organizar el registro y seguimiento de las solicitudes de los clientes, la actualización del inventario, la asignación de stock disponible y las notificaciones sobre la disponibilidad de los productos.

Proceso de negocio

El proceso contempla las siguientes actividades:
- Consulta del cliente por un producto.
- Verificación de la disponibilidad de stock.
- Registro de solicitudes cuando no hay stock suficiente.
- Organización de las solicitudes pendientes por antigüedad.
- Asignación de mercadería disponible.
- Notificación al cliente cuando puede retirar el producto.
- Cancelación de solicitudes vencidas y liberación del stock reservado.
  
Modelado del proceso

El proceso organizativo se representa mediante un diagrama BPMN, utilizando pools, lanes, tareas, eventos, compuertas de decisión y flujos de secuencia y de mensaje.
